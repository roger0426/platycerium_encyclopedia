# 鹿角蕨物種／交種清單（初稿）

> **2026-10-14 更新：** 本清單已全部匯入 `data/plants.csv`（原生種 18、雜交種 48、品系 52），之後以 CSV 為準，這份檔案只保留作為初次蒐集的紀錄。
> 匯入時修正的錯誤：「非猴」是 **P. madagascariense**（非洲猴腦），不是 ridleyi（亞猴）。所以「非非 = 非猴 × 非圓 = 'Horne's Surprise'」、「非象 = 非猴 × 象耳 = 'Erawan'」、「非Q = 非猴 × 四叉 = 'Budsaba'」，下方 C 表中的這兩列寫錯了。

> 2026-10-14 網路初步蒐集，供後續逐一深入 survey 使用。
> 交種親本多來自業者與玩家資料，**未經 DNA 驗證者一律視為「待查」**；同名不同親本、正反交方向不明的情況很常見。
>
> 狀態欄：✅ = 已在 `data/plants.csv`　⬜ = 尚未建檔

## 三、待決事項

1. 俗名衝突：「非非」、「立葉」、「巨獸」各有兩種指稱，網站上要定一套主名＋別名。
2. 重複組合：Elemaria／Antis、Neptune／Luaentii、kitshakoodiense／ridleyi×coronarium、Diversifolium／hillii×bifurcatum 要決定是合併還是分開。
3. 是否把「品系／產地型」（Mt. Lewis、爪哇各品系）納入 plants.csv，可能需要新增 `type = cultivar`。
